# Duck Search 🦆

Duck Search is a small hobby project I made for fun.

It is a simple search homepage powered by DuckDuckGo, built with HTML, CSS and JavaScript.

## Features

- DuckDuckGo search
- Responsive layout
- Custom gradient background
- Enter key support
- Opens results in a new tab
